# stm32-micro-sd-card-module
This project is implemented using the STM32F103ZET6 microcontroller. Its primary function is to interface with an SD card module to provide data storage capabilities. Within the `diskio.c` file, an offset of +32 (relative to the logical sector number) is applied to translate logical sectors into physical sectors; if the starting sector changes—for instance, after reformatting the card—this offset must be adjusted accordingly. Furthermore, since the file creation timestamp for text documents is pre-configured within `ffconf.h`, integrating an RTC (Real-Time Clock) module is necessary if you require files to be stamped with the actual real-time clock. The pin assignments and wiring definitions can be found in the `SPI.c` file.
This SD card module utilizes the SPI communication protocol rather than SDIO; you can change the specific SPI interface you wish to use by adjusting the pin definitions within the SPI configuration file.
